# 놀곳 컬러 시스템 — 색채심리학 근거

> 전제: 색채심리 효과는 **맥락에 따라 달라진다** (Elliot & Maier, 2014 *Color Psychology* 리뷰의 "color-in-context" 이론).
> "주황 = 무조건 구매 증가" 같은 단정은 근거가 약하다. 아래는 **연구로 비교적 일관되게 확인된 원리**와
> **관습(사용자가 이미 학습한 의미)** 을 우선해 적용한 것이다. 사용자 선호: **핑크 사용 금지.**

## 1. 적용한 원리

| 원리 | 근거 | 놀곳에서 |
|---|---|---|
| 따뜻한 색(빨강·주황·노랑)은 각성(arousal)·활력을 높이고, 차가운 색은 진정 | Valdez & Mehrabian (1994): 채도·명도가 감정 반응을 좌우, 채도↑ → 각성↑ | '놀러 가자'는 들뜬 기분 → 브랜드 주색 **주황** |
| 채도가 높은 색을 넓게 쓰면 피로·과자극 | 같은 연구 + 60-30-10 배분 관습 | 주황은 **10% 포인트**(CTA·선택 상태)에만. 배경은 저채도 크림 |
| 빨강은 주의·긴급·회피(위험) 신호 | Elliot et al. (2007): 빨강 노출 시 회피 동기 | 빨강 계열은 **'오늘 마감/마감 임박' 한 곳**에만. 일반 버튼에 쓰지 않음 |
| 파랑은 신뢰·안정·정보 | 브랜드/UI 연구 전반에서 일관 + 링크=파랑 관습 | 링크, 정보성 요소, 오디오가이드 |
| 초록은 '가능/안전/완료' (신호등 관습) | 학습된 의미 | **무료** 태그, 진행중 상태, 토글 ON, 성공 토스트 |
| 노랑·앰버는 낙관·주의 환기 | 학습된 의미(경고/하이라이트) | '곧 시작(D-n)', 이번 주말 하이라이트, 반짝이 |
| 따뜻한 무채색(크림·웜그레이)은 편안함, 순백·순흑은 눈부심·대비 피로 | 다크모드 가독성 가이드(순흑 #000 위 순백 텍스트는 halation) | 배경 #faf6ef, 다크모드는 웜 차콜 #14110e |
| 한국 달력 관습: 일요일·공휴일 빨강, 토요일 파랑 | 문화적 학습 | 캘린더 요일 색 유지 |
| 색만으로 정보를 전달하지 않기 | WCAG 1.4.1, 한국 남성 약 5.9%가 색각이상 | 상태·카테고리는 항상 **텍스트/아이콘 + 색** 함께. 빨강-초록 쌍을 유일한 구분으로 쓰지 않음 |
| 고립 효과(von Restorff) | 주변과 다른 것이 기억에 남음 | 홈 화면에 파랑·초록 앱이 많음 → **주황 아이콘**이 눈에 띔 |
| 카테고리별 고유 색 → 전주의적(pre-attentive) 처리로 빠른 탐색 | 시각 탐색 연구(색은 가장 빠른 전주의 속성 중 하나) | 6개 kind마다 고유 색상, **명도·채도는 맞춰** 어느 하나만 튀지 않게 |

## 2. 토큰

### 브랜드 / 의미색 (Light → Dark)
| 토큰 | Light | Dark | 역할 |
|---|---|---|---|
| `--accent` | `#f26a1b` | `#ff8a3d` | 브랜드·주 CTA·선택 상태 (에너지, 사교성) |
| `--accent-text` | `#b4470b` | `#ffb07a` | 주황 위 텍스트 대신 쓰는 AA 대비 텍스트 |
| `--accent-soft` | `#fff0dc` | `#3a2414` | 칩·배너 배경 (크림-앰버) |
| `--urgent` | `#d6361a` | `#ff6a4d` | **오직** 마감 임박·오늘 마감 |
| `--positive` | `#2f8f5b` | `#4fc184` | 무료·진행중·완료 |
| `--info` | `#2563eb` | `#7aa7ff` | 링크·정보 |
| `--highlight` | `#f5a524` | `#ffc35a` | D-n·주말 하이라이트·반짝이 |
| `--bg` | `#faf6ef` | `#14110e` | 웜 크림 / 웜 차콜 |

| `--text` | `#1f1a14` | `#f5efe6` | 본문 |

### 카테고리 (kind) 색
| kind | 색 | 심리적 연상 |
|---|---|---|
| festival 축제·행사 | 주황 `#f26a1b` | 축제·흥·사교 |
| performance 공연 | 인디고 `#4f46e5` | 밤·몰입·창의 (보라-핑크 쪽으로 가지 않게 파랑 쪽 인디고) |
| exhibition 전시 | 틸 `#0f8f86` | 차분함·사색 |
| workshop 클래스 | 오커 `#b7791f` | 손·공예·따뜻함 |
| tour 가이드투어 | 그린 `#2f8f5b` | 야외·걷기·자연 |
| audioguide 오디오가이드 | 블루 `#2563eb` | 듣기·신뢰·안정 |

각 kind는 `--k`(진한색, 텍스트·아이콘)와 `--k-soft`(옅은 배경) 한 쌍으로 쓴다. 다크모드에서는 명도를 올린 버전 사용.

## 3. 아이콘 (플랫)
- 배경: 브랜드 주황 `#f26a1b` **단색** — 에너지·사교성. 홈 화면의 파랑·초록 앱 사이에서 고립 효과로 눈에 띔.
- 티켓: 웜 화이트 `#fffbf4` 본체 + 크림-앰버 `#fff1dc` 스텁, 앰버 절취선. 그림자는 블러 없는 **단색 하드 섀도**(`#c9500f`).
- 하트: 레드오렌지 `#e2400e` 단색 — '관심 저장'의 의미, 순수 빨강(위험·경고)은 피함.
- 반짝이: 연노랑 `#ffe9a8` — 발견의 기쁨, 낙관.
- 그라데이션·글로우·광택 하이라이트 없음. 핑크·마젠타 없음.

## 3-1. 그라데이션 금지 — 근거
- **포스터가 주인공**: 실제 이벤트 포스터는 이미 색과 정보가 많다. UI가 단색이면 시선이 포스터로 모이고, UI 장식과 포스터가 경쟁하지 않는다 (시각적 위계).
- **시각적 소음 감소**: 그라데이션은 면마다 명도 변화를 만들어 주의를 분산시킨다. 단색 면은 '배경'으로 빠르게 인식돼 콘텐츠 탐색이 빨라진다.
- **색의 의미 보존**: 이 시스템은 색에 역할(주황=행동, 초록=무료/진행, 빨강=마감)을 준다. 그라데이션으로 색이 섞이면 의미가 흐려진다.
- **일관성·대비 검증 가능**: 단색은 모든 지점의 대비가 같아 WCAG 검증이 확실하다. 그라데이션 위 텍스트는 가장 약한 지점에서 대비가 무너진다.
- 이미지가 없는 이벤트는 그라데이션+이모지 대신 kind 색의 **단색 텍스트 카드**(`.poster.noimg`)로 표시한다 — 의도된 편집 디자인처럼 보이게.
- 허용: 단색, 반투명 단색(블러 바 등), 미묘한 그림자. 금지: linear/radial/conic-gradient, 페이드 마스크, 글로우.

## 4. 금지 규칙
1. 핑크·마젠타·로즈 계열 사용 금지.
2. `--urgent`(빨강)는 마감 임박 표시 외에 쓰지 않는다. 삭제/초기화 같은 파괴적 동작은 예외적으로 허용.
3. 한 화면에 채도 높은 주황 면적이 10%를 넘지 않게. 큰 면은 `--accent-soft`.
4. 색만으로 상태를 구분하지 않는다 (항상 텍스트 라벨 동반).
5. 모든 텍스트 대비 WCAG AA (본문 4.5:1, 큰 글씨 3:1) 이상.
6. **그라데이션 금지** — CSS·아이콘·이미지 오버레이 어디에도 (§3-1). 이미지 위 텍스트는 단색 스크림 띠로.
